# 智能货运在途监控与实时偏航预警系统 Demo (生产级验证平台)

本项目是针对**货车 A 到 B 点路径规划、实时位置上报、偏航智能预警以及断网补传机制**的高仿真交互式验证原型，代码架构与生产级系统完全对齐。

---

## 快速运行指南

无需安装任何后端或数据库环境，**直接双击根目录下的 `index.html` 即可在任意现代浏览器（Chrome / Edge / Safari）中直接运行并体验**！

---

## 核心体验模块与操作指南

### 1. 货车规则与路线规划
- **左侧面板**展示了货车物理属性（长 13.5m、宽 2.55m、高 4.0m、总重 36.0t、4轴）。
- 点击 **“重新生成最佳合规路线”**，地图上将生成一条从**“广州黄埔港”**到**“东莞清溪智能产业园”**的基准规划折线（深蓝色高亮），并自动生成外扩的**浅蓝色管道安全缓冲区（Corridor Buffer）**。

### 2. 仿真场景演练（核心测试功能）
- 点击 **“▶️ 模拟正常按线行驶”**：
  - 货车沿着规划路线平稳行进，小车带绿色脉冲雷达环。
  - 右上角 HUD 仪表盘实时显示车速（70~80 km/h）、距基线垂直距离（10~30米小幅波动），系统保持“安全受控通行”状态，不触发报警。
- 点击 **“⚠️ 模拟擅自下道偏航”**：
  - 模拟货车离开高速主线转入省道。
  - 点到折线的垂直距离快速攀升至 **300m ~ 1000m** 以上。
  - 触发**连续滑动窗口防漂移算法**，超出阈值连续 3 次后，顶部弹出**红色声光警报横幅**，播放**急促双频警报音**，轨迹实时切换为**红色报警实线**，调度大屏输出偏航流水工单。
- 点击 **“🚇 模拟进隧道(断网离线)”**：
  - 模拟车辆进入山区/隧道，顶部网络状态显示**“离线 (隧道无信号)”**。
  - 启动 **Store & Forward 本地持久化暂存队列**，左侧面板的“本地待上报队列”实时累积计数。
  - 行驶 5 周期后自动出隧道，网络恢复，触发**自动批量补传**，历史轨迹瞬间缝合对齐！
- 点击 **“🔄 车辆复位重置”**：
  - 还原初始状态。

## 生产级代码架构对应关系

| 本 Demo 文件 | 生产级系统对应组件 | 职责说明 |
| :--- | :--- | :--- |
| `js/routeEngine.js` | 高德开放平台 `AMap.TruckDriving` API | 负责结合货车限行/限高/限重参数生成高密度的路线折线序列 (Polyline) 与安全缓冲面 (Buffer) |
| `js/deviationDetector.js` | 后端流计算引擎 / Turf.js / Java JTS | 实现点到折线的垂直最短距离算法，结合连续滑动窗口排除 GPS 漂移和加油站短暂误报 |
| `js/offlineStorage.js` | 移动端本地 SQLite 存储转发器 | 实现进隧道断网暂存，出隧道监听网络恢复并批量 Gzip 压缩补发的可靠数据管道 |
| `js/audioAlarm.js` | 司机端车载音频与语音播报组件 | 偏航发生时的车载急促警示音与语音提醒 |
| `js/simulator.js` | 车载 GPS/北斗上报数据源 | 模拟 GPS / 4G 模组定时经纬度推流 |
| `js/app.js` | TMS/OMS 调度大屏前端控制逻辑 | 实时轨迹绘制、偏航警报横幅、双端联动展示 |
